# SOLARIS 3D – Interactive 3D Solar System Simulator

## Project Overview

SOLARIS 3D is an interactive 3D Solar System Simulator developed using Python as a Computer Graphics project. It demonstrates important computer graphics concepts through a visual simulation of the Sun and planets.

The project implements a custom 3D software rendering pipeline and provides interactive controls to explore transformations, projections, camera movements, lighting, shading, and 2D graphics algorithms.

## Objectives

- To understand and implement fundamental Computer Graphics concepts.
- To demonstrate 3D transformations using 4×4 matrices.
- To implement perspective and orthographic projections.
- To understand lighting and shading techniques.
- To demonstrate 2D line drawing, circle drawing, and clipping algorithms.
- To create an interactive solar system simulation.

## Technologies Used

- **Programming Language:** Python
- **GUI:** Tkinter
- **Mathematics:** Python Math Library
- **Graphics:** Custom 3D Software Rendering Pipeline
