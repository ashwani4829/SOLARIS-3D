# SOLARIS 3D – Interactive 3D Solar System Simulator

## Project Overview

SOLARIS 3D is an interactive 3D Solar System Simulator developed using Python as a Computer Graphics project. It demonstrates fundamental computer graphics concepts through a visual simulation of the Sun and planets.

The project uses a custom 3D software rendering pipeline and provides interactive controls to explore 3D transformations, projections, camera movements, lighting, shading, parametric curves, and 2D graphics algorithms.

## Objectives

- To understand and implement fundamental Computer Graphics concepts.
- To demonstrate 3D transformations using 4×4 matrices.
- To implement perspective and orthographic projections.
- To understand lighting and shading techniques.
- To demonstrate 2D line drawing, circle drawing, and clipping algorithms.
- To develop an interactive solar system simulation.

## Technologies Used

- **Programming Language:** Python
- **GUI:** Tkinter
- **Mathematics:** Python Math Library
- **Graphics:** Custom 3D Software Rendering Pipeline

## Features

### 1. Interactive 3D Solar System
- Visualization of the Sun and planets.
- Planetary orbital movement and rotation.
- Interactive solar system simulation.
- Planet selection and simulation controls.

### 2. 3D Transformations
- Translation
- Rotation
- Scaling
- Reflection
- 4×4 Homogeneous Transformation Matrices

### 3. Projection and Camera
- Perspective Projection
- Orthographic Projection
- Camera rotation and zoom
- Interactive camera controls

### 4. Lighting and Shading
- Blinn-Phong Shading
- Lambertian Shading
- Toon Shading
- Surface Normals
- Wireframe Rendering
- Unlit Rendering

### 5. Parametric Curves
- Bézier Curve
- B-Spline Curve
- Hermite Curve

### 6. 2D Computer Graphics Algorithms

The project demonstrates the following 2D graphics algorithms:

- DDA Line Drawing Algorithm
- Bresenham Line Drawing Algorithm
- Midpoint Circle Drawing Algorithm
- Cohen-Sutherland Line Clipping Algorithm

### 7. Matrix Inspector
- Displays transformation matrices.
- Helps understand Model, View, and Projection matrices.
- Demonstrates the role of matrices in 3D graphics.

## Installation and Execution

### Prerequisites

- Python 3.10 or later recommended.
- Tkinter installed and available in Python.
- Both Python source files must be present in the same project folder.

### Step 1: Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### Step 2: Open the Project Folder

```bash
cd SOLARIS-3D
```

### Step 3: Run the Application

```bash
python solar_system_3d_tkinter.py
```

**Note:** The application should be tested with the provided supporting module before considering the project fully runnable.
